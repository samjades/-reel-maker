2. Narration and sound

For embedded narration, upload a narration audio file. Browser speech preview cannot be captured reliably by web apps. To generate a Nigerian-accented voice without a paid API, use a local TTS engine such as Piper/Kokoro on your own computer and upload its audio output. Device voices may not include a Nigerian accent.

3. Export

WebM recording is browser-native. MP4 export loads FFmpeg WebAssembly from a CDN on first use, so it needs internet access and may be slow on mobile. It is not a paid API.

Optional local AI scenes: This app is ready to be extended with a local image/video model. GitHub Pages cannot run a large AI model itself; the model must run on a compatible computer or GPU server. This MVP uses original vector animation and does not call an AI API.
